# Sistema de Reserva de Recursos

##### 

#### Proyecto 1 de EIF206 - Programación 3. Profesor: Juan de Dios Murillo Morera.





###### Aplicación de escritorio desarrollada en Java para gestionar reservas de recursos institucionales.

###### El sistema utiliza interfaz gráfica con Swing, persistencia en archivos XML, arquitectura por capas y el patrón Modelo-Vista-Controlador.

##### 

##### **1. Funcionalidades principales.**

##### 

###### \* Inicio de sesión y cambio de contraseña.

###### \* Gestión de reservas por parte de funcionarios.

###### \* Validación de disponibilidad de recursos.

###### \* Cancelación de reservas futuras.

###### \* Autocompletado del formulario de reserva mediante Gemini.

###### \* CRUD de funcionarios, categorías y recursos para administradores.

###### \* Calendarización de recursos y actividades.

###### \* Estadísticas con tablas y gráficos de barras.

###### \* Generación de reportes en PDF.

###### \* Pruebas unitarias y de integración.

##### 

##### **2. Requisitos.**

##### 

###### \* Java 17.

###### \* IntelliJ IDEA.

###### \* Maven.

##### 

##### **3. Cómo ejecutar el proyecto.**

##### 

###### 1\. Descomprimir el proyecto.

###### 2\. Abrir en IntelliJ la carpeta que contiene pom.xml, la carpeta src y los archivos XML.

###### 3\. Ejecutar la clase Main.

###### 

###### Los archivos administradores.xml, funcionarios.xml, categorias.xml, recursos.xml y reservas.xml deben permanecer en la carpeta raíz del proyecto, junto a pom.xml.

##### 

##### **4. Pruebas.**

##### 

###### \* mvn test ejecuta las pruebas unitarias.

###### \* mvn verify ejecuta las pruebas unitarias y de integración.

##### 

##### **5. Inteligencia Artificial.**

##### 

###### La clave de Gemini se solicita desde la interfaz cuando se necesita utilizar la función de autocompletado. La clave solo se mantiene durante la ejecución actual y no se almacena en el código ni en el repositorio.
